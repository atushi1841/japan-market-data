Japan Market Data API

Japanese resale markets are large, fragmented and almost entirely published in Japanese. The price signal sits behind search pages that are rendered client-side, paginated, and rate-limited — which is why most price-tracking projects stall on the data layer before they reach the interesting part.

These scrapers run on the Apify cloud and return one clean JSON record per listing: item name, current price in JPY, condition, image URL, listing URL and timestamps. You pay per result, so a full sweep of a niche catalogue typically costs less than a dollar.

What you get

item_nameListing title exactly as the marketplace publishes it.
current_price_jpyAsking price in Japanese yen, unformatted.
conditionSeller-declared condition grade where the marketplace exposes one.
item_urlCanonical listing URL for reprocessing or manual review.
image_urlPrimary listing image, hot-linkable for catalogues.
sold_atTimestamp for sold/ended listings on auction sources.

Field names follow the actor's dataset schema and can differ slightly between actors — check the actor page for the exact input and output schema before wiring it into a pipeline.

Use cases

  • Build a price index for a specific collectible category before deciding what stock to source.
  • Feed an LLM agent with live Japanese pricing instead of stale training data.
  • Monitor a watchlist of items and alert when the asking price drops below a threshold.
  • Export a category-wide dataset to CSV for spreadsheet review or BI tools.

How a run works

Starting a run: pick the actor for your marketplace from the publisher page, then start it from the Apify console or the API. Billing is per result returned (roughly $0.002 per item), so a scoped search stays cheap.

curl "https://api.apify.com/v2/datasets/$DATASET_ID/items?token=$APIFY_TOKEN&format=json"

FAQ

Which marketplaces are covered?
The current set is Mandarake auction (figures, manga, trading cards), DLsite (doujin, voice, ASMR), Mercari Japan (C2C listings), and an official MLIT real estate transaction price API. The publisher page lists exactly what is live right now, so check it before planning a pipeline.
Do I need a Japanese IP address?
No. The scrapers run on Apify infrastructure and handle the regional access themselves; you only consume the dataset.
How is billing calculated?
Per result returned, roughly $0.002 per item, so cost scales with how much data you actually pull rather than a flat monthly seat.
