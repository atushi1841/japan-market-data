Japan Collectibles Price API

Collectible pricing rewards specificity. A generic 'used figure' price is close to useless, while a price for one character, one scale, one grade and one edition is immediately actionable — and that granularity only comes from listing-level data.

These scrapers return listing-level records across the Japanese collectible floors, so you can slice by series, grade and marketplace instead of relying on an aggregate that averages away the difference.

Mandarake Auction Scraper → All Japanese market scrapers →

What you get

item_nameTitle carrying series, scale and edition markers.
current_price_jpyPrice in yen.
conditionGrade — the main price-setting variable for collectibles.
item_urlListing URL.
image_urlPhoto for edition verification.

Field names follow the actor's dataset schema and can differ slightly between actors — check the actor page for the exact input and output schema before wiring it into a pipeline.

Use cases

  • Build a graded price guide for a figure or card series.
  • Spot the price effect of a rerun announcement within days.
  • Price an incoming collection acquisition before making an offer.

How a run works

Starting a run: call the Apify API with the actor id fruitful_quintessence~mandarake-auction-scraper, or press Start on the actor page and download the dataset. Check the actor page for its exact input schema — a run is scoped by the search terms you supply, and billing is per result returned (roughly $0.002 per item).

curl -X POST "https://api.apify.com/v2/acts/fruitful_quintessence~mandarake-auction-scraper/runs?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["your", "search", "terms"]}'

FAQ

Which collectible categories are covered?
Figures, manga, trading cards and doujin works are covered across the Mandarake and DLsite scrapers; the publisher page lists each actor.
Can I compare across marketplaces?
Yes — run more than one actor and keep the source URL with each record.
Is grading data standardised?
Grades follow each source's own convention, so treat them as source-published labels rather than a unified scale.
