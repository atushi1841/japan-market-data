Python×Apifyで日本の中古市場データをスクレイピング 。 Mercari・ヤフオク・ラクマの実装例

日本の中古市場（Mercari、Yahoo!オークション、ラクマなど）から構造化データを取得するためのApify Actor群を公開しています。

なぜApify Actorなのか

日本のマーケットプレイスはAPIが限られており、構造化された情報を得るのが困難です。これらのActorはスクレイピングの複雑さを隠蔽し、リアルタイムの価格・出品データを提供します。

Getting started

各ActorにはExample run input、Dataset output（JSON/CSV）、Scheduled runs機能が付きます。

from apify import ApifyClient

client = ApifyClient(token="YOUR_APIFY_TOKEN")

# Mercari検索例
run = client.actor("fruitful_quintessence/mercari-japan-search-scraper").call(
    input_override={"searchTerms": "Nintendo Switch", "maxItems": 100}
)

# データ取得
data = run.data_items

データ分析例

import json

# データロード
with open("mercari_data.json") as f:
    items = json.load(f)

# 価格分布分析
prices = [item["price"] for item in items if "price" in item]
print(f"平均価格: {sum(prices)/len(prices):.0f}円")
print(f"中央値: {sorted(prices)[len(prices)//2]}円")
