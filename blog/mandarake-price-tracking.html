How to Track Mandarake Prices Automatically

A concrete guide to monitoring Japanese anime figure / manga prices without refreshing the site all day.

If you collect anime figures, manga, or doujin trading goods, you already know Mandarake — Japan's largest second-hand otaku marketplace — is where hard-to-find items surface. The problem: hot items sell in minutes, and prices swing daily. Watching dozens of search terms by hand is impossible.

This guide covers a practical, cheap way to automatically monitor Mandarake auction and listing prices, get notified on drops, and keep historical data for "is this a good price?" decisions.

1. What data you actually need

For effective price watching you want, per item:

  • Item name / series / character
  • Current price in JPY
  • Condition (mint / used / damaged)
  • Sold or available status
  • Listing URL and image
  • Timestamp so you can chart the price over time

That last field is the one people usually forget — a single snapshot tells you nothing. Price history is what lets you spot a bargain or an overpriced listing before you commit.

2. Two ways to collect the data

Hand-rolling a scraper against Mandarake is brittle — the site is JS-heavy and blocks datacenter traffic. The reliable shortcut is a cloud scraped-data API that returns clean JSON.

Recommended: the Mandarake Auction Scraper runs on the Apify cloud, searches any keyword or the full category tree, and returns structured rows — item, current price JPY, url, images, condition. It's billed per result (~$0.002/item), so a full sweep of one category costs well under $1.

If you'd rather write it yourself: Mandarake has search URLs of the form https://order.mandarake.co.jp/order/listPage/list?category=.... In practice, you'll fight pagination and bot protection — which is why most people use the cloud API and spend their time on the data, not on keeping a scraper alive.

3. Turn the data into price-drop alerts

Pull the dataset on a schedule (the Apify actor supports recurring runs), compare each item's current price against a threshold or a stored "last seen" value, and only alert when it crosses:

for item in dataset:
    if item.current_price_jpy <= threshold[item.name]:
        notify(item, "price dropped to " + str(item.current_price_jpy))

Pipe alerts to Telegram, Discord or email. You now have a watchlist that never sleeps.

4. Export to CSV for decisions

Most of these APIs let you download the full run as CSV/JSON. Keep a dated export and you build your own price-history database — useful both for buying decisions and, if you resell, for justifying your asking price.

5. Don't store seller personal data

Stick to item + price + URL + timestamp. That's all you need, and it keeps you clear of Japan's personal-information rules around listing seller identities.

Bottom line

Automatic Mandarake price monitoring is a small project with a big payoff for anime/trading-card collectors: stop refreshing, start deciding. For the data layer, use the Mandarake Auction Scraper and put your effort into the alerting and history logic that actually saves you money.
