Japan Real Estate Price Data

Japanese property listing portals show asking prices, which is a different number from what transactions actually cleared at. For any serious valuation work the useful figure is the recorded transaction price, and in Japan that data is published by the government through the MLIT Reinfolib dataset.

This actor queries that dataset and returns structured JSON: transaction price, floor area, location, building information and zoning, covering all 47 prefectures. Because the underlying source is the official land and property transaction record rather than a broker's listing, it stands up as evidence in an appraisal or investment memo.

FAQ

Where does the data come from?
The national MLIT Reinfolib transaction price dataset, queried through the actor. It is official government-published transaction data rather than portal listings.
How current are the records?
The underlying dataset is updated periodically by the ministry, so treat the returned set as the latest published batch rather than real-time sale prices.
Can I filter by prefecture or period?
Yes — the run is scoped by the query parameters you supply, which is what makes prefecture-level and period-level analysis practical.
