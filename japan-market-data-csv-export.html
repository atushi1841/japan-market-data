Japan Market Data to CSV

Not every analysis needs a pipeline. A surprising amount of useful work happens in a spreadsheet: sorting a category by price, filtering to a condition grade, and eyeballing where the outliers sit.

Apify datasets export directly to CSV, Excel and JSON, so the practical workflow is to run a scoped search, export the rows, and open the file. For recurring work, the same dataset feeds Python or a BI tool without changing anything upstream.

What you get

item_nameColumn for sorting and filtering.
current_price_jpyNumeric column, safe to sort and aggregate in a spreadsheet.
conditionFilter column for separating grades.
item_urlReference column for opening the original listing.
image_urlImage column for visual review.

Field names follow the actor's dataset schema and can differ slightly between actors — check the actor page for the exact input and output schema before wiring it into a pipeline.

Use cases

  • Hand a category overview to a colleague who works in spreadsheets, not JSON.
  • Filter a category to one grade and sort by price to find the cheapest acceptable copy.
  • Archive a dated export as a price snapshot for later comparison.

How a run works

Starting a run: pick the actor for your marketplace from the publisher page, then start it from the Apify console or the API. Billing is per result returned (roughly $0.002 per item), so a scoped search stays cheap.

curl "https://api.apify.com/v2/datasets/$DATASET_ID/items?token=$APIFY_TOKEN&format=json"

FAQ

Which formats are available?
Datasets export to CSV, JSON, Excel and other common formats directly from the run's dataset view.
Do I need to write code?
No. A run can be started from the Apify console and the dataset downloaded from the UI; code is optional for automation.
How do I compare two snapshots?
Export both, match rows on item_url, and compare the price column — the same diff approach as an API-driven monitor.
